Abstract

Segmenting a 3D object into semantically meaningful parts requires joint reasoning about geometric structure and semantic context. Pretrained 3D experts provide spatially grounded region proposals, while 2D experts provide semantic cues for identifying object parts. The challenge is to integrate these complementary capabilities into a framework that can both produce meaningful part segmentations and progressively refine them. We present PartAgent, a training-free agentic framework for 3D part segmentation built upon two complementary modules: (i) Structural–Semantic Expert Integration combines regions predicted by the 3D expert with multiview semantic evidence from the 2D expert through image-to-surface correspondences, constructing compositional part partitions at multiple granularities. (ii) Observation-Driven Closed-Loop Partition Refinement observes the current partition and its supporting evidence to select targeted inspection, evidence repair, composition, or reselection actions. It verifies proposed changes and uses the updated state and action outcomes to guide subsequent decisions. On PartObjaverse-Tiny-WT, PartAgent achieves 68.41 mIoU, outperforming the strongest competing method by 8.53 points. Across 3DCoMPaT200, PartNeXt, PartNetE, and PartObjaverse-Tiny, PartAgent achieves the highest mIoU on each dataset, averaging 69.36 across the four datasets, 7.28 points above the highest mean among competing methods. All code and results will be released.

How PartAgent works

Follow one tractor from 3D expert regions and 2D semantic masks to the initial partition. Then see what prompts the agent to inspect the rear wheel, regroup its regions, and verify the change.

SSEI

Structural–Semantic Expert Integration

PartAgent uses image-to-surface correspondences to map multiview semantic evidence onto the 3D expert regions. On the tractor, the fender and part of the tire become distinct integrated leaves within one such region. The mask tree records groupings of leaves. A vision–language model (VLM) proposes additional groupings in a directed acyclic graph (DAG). From these groups, PartAgent builds candidate partitions at multiple granularities. The VLM compares their projections with the original renders and semantic evidence to select the initial partition.

CLR

Observation-Driven Closed-Loop Partition Refinement

The VLM observes the current partition alongside the geometry, leaf IDs, and 2D masks in the same views. On the tractor, Inspect returns a closer view of the rear wheel. The fender and tire share a region, while the wheel is split in two. The agent chooses Compose to regroup the existing leaves. A separate VLM call checks the current partition and the proposal against the original renders. Once the change is accepted, the updated state and verification feedback guide the next inspection of the exhaust.
